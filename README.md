
# Telegram-бот для отслеживания работы
Этот проект представляет собой Telegram-бота, который позволяет пользователям настраивать свой рабочий график и отслеживать текущую рабочую задачу. Пользователи могут отправлять выполненную работу через бота.

## Команды

/***start*** или в ***начало*** ↩️ - возвращаю в главное меню.
____________________
/***current_work*** или ***текущая работа*** ⏱ - показываю текущую работу.
____________________
/***send work*** или ***отправить работу*** 📧 - отправляю работу на проверку с твоим комментарием. После проверки верну информацию о работе.
____________________
/***archive*** или ***архив работ*** 🗄️ - показываю прошлые сделанные работы.
____________________
/***timetable*** или ***график работы*** 🗓 - отправляю ссылку на таблицу с расписанием.
____________________


### Примечания
**Бот** использует базу данных SQLite для хранения данных пользователей и работ.
____________________
**Бот** использует aiogram для работы с Telegram API.
____________________
**Бот** использует sqlalchemy для работы с базой данных.
____________________
**Бот** использует python-telegram-bot для работы с Telegram API.
____________________
**Бот** использует markdown для форматирования текста.
____________________
**Бот** использует SimpleCalendar для работы с календарем.
